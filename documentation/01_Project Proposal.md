MentorLink – A Skill Exchange and Mentorship Platform for University Students
Project Type: Personal Portfolio Project
Project Category: Full-Stack Web Application
Project Purpose: Skill Development & Portfolio Building
Developed By: Malki Navodya
Technology Stack: Laravel • Angular • MySQL • Git • GitHub
Development Methodology: Agile
Project Status: In Development
Version: 1.0

1. Introduction
MentorLink is a personal software engineering project developed to strengthen full-stack development skills while solving a real-world problem faced by university students.
The platform connects students who are willing to share their knowledge with those who want to learn new skills. By creating a structured environment for peer mentoring and skill exchange, MentorLink encourages collaborative learning and professional growth within universities.
This project also serves as a portfolio application demonstrating modern software engineering practices, including system design, REST API development, responsive frontend development, database design, authentication, version control, testing, and deployment.

2. Background
University students often need help outside the classroom. Some students excel in programming, UI/UX design, networking, mathematics, English, or public speaking, while others are looking for guidance in those same areas.
Although students usually seek help through WhatsApp groups, social media, or personal contacts, these methods are informal and make it difficult to find the right mentor at the right time.
MentorLink provides a dedicated platform where students can create profiles, list their skills, discover mentors, and collaborate in an organized way.

3. Problem Statement
There is no centralized platform in many universities that allows students to discover peer mentors based on specific skills and interests.
As a result:
•	Students struggle to find knowledgeable peers.
•	Skilled students have limited opportunities to mentor others.
•	Knowledge sharing depends on personal networks.
•	Valuable learning opportunities are missed.

4. Proposed Solution
MentorLink is a web application that allows university students to:
•	Create personal profiles.
•	Showcase skills they can teach.
•	Search for mentors.
•	Send mentorship requests.
•	Communicate through the platform.
•	Build a reputation through reviews and ratings.
The system creates a structured environment for peer learning while encouraging collaboration and continuous skill development.
