# MentorLink

## Project Description

MentorLink is a skill exchange and mentorship platform that connects learners with mentors to share knowledge and improve skills.

## Purpose

The purpose of this project is to create a platform where students and professionals can teach and learn skills from each other.

## Technologies

### Frontend
- Angular

### Backend
- Laravel

### Database
- MySQL

### Tools
- Git
- GitHub
- Postman
- Figma

## Main Features

- User registration and login
- User profiles
- Skill management
- Mentor search
- Learning requests
- Reviews and ratings
- Messaging system
